QUICK REFERENCE

Resolution playbook

A simple workflow for investigating a software incident.

01

Identify

Record the affected application, symptoms, start time, and environment. Capture the exact error message if available.

02

Assess impact

Determine how many users are affected and whether critical business functions are unavailable.

03

Prioritise

Use the suggested severity as a starting point. A responsible support person should confirm priority.

04

Investigate & resolve

Review recent changes, check logs, test a safe fix, and document the outcome before marking an incident resolved.

Prototype limitation

The included assistant is a guided, rule-based demo. It is not connected to a live AI model, monitoring service, or shared database.
